# HuNav Gazebo Wrapper - Directory Structure

## Organization

Files are organized by **world/environment** to support multi-environment testing and scalability.

### Scenarios (`scenarios/domenic/`)

```
scenarios/domenic/
├── cafe/                          # Café environment - small to medium
│   ├── cafe_oat_balanced_baseline.yaml        # 12 agents (baseline)
│   ├── cafe_oat_social_low.yaml               # 12 agents (↓ social force)
│   ├── cafe_oat_social_high.yaml              # 12 agents (↑ social force)
│   ├── cafe_oat_goal_low.yaml                 # 12 agents (↓ goal attraction)
│   ├── cafe_oat_goal_high.yaml                # 12 agents (↑ goal attraction)
│   ├── cafe_oat_speed_slow.yaml               # 12 agents (↓ walking speed)
│   └── cafe_oat_speed_fast.yaml               # 12 agents (↑ walking speed)
├── warehouse/                     # Warehouse environment - large
│   └── (placeholder for future tests)
├── house/                         # House environment - small
│   └── (placeholder for future tests)
└── central_tunnel/                # Central tunnel environment - linear
    └── (placeholder for future tests)
```

**Naming Convention:**
- `cafe_oat_[variation_name].yaml` - One-At-A-Time (OAT) sensitivity analysis configuration
- Each file contains 12 agents with sampled parameters + 10 global waypoint goals
- Generated by `src/DATASETS/domenic_analysis/generate_oat_scenarios.py`

### Behavior Trees (`behavior_trees/`)

```
behavior_trees/
├── cafe/                          # Café behavior trees (12 agents)
│   ├── agents_cafe__agent_1_bt.xml
│   ├── agents_cafe__agent_2_bt.xml
│   ├── ...
│   └── agents_cafe__agent_12_bt.xml
├── warehouse/                     # Warehouse behavior trees (placeholder)
│   └── (placeholder for future tests)
├── house/                         # House behavior trees (placeholder)
│   └── (placeholder for future tests)
└── central_tunnel/                # Central tunnel behavior trees (placeholder)
    └── (placeholder for future tests)
```

**Naming Convention:**
- `agents_[world]__agent_[id]_bt.xml` - World-specific behavior tree for agent ID
- Uses generic `{id}` placeholder for dynamic agent ID injection
- All agents in a world use the same behavior tree template (system substitutes actual ID at runtime)

## Key Design Decisions

### Why World-Specific Organization?

1. **Scalability:** Each world can have different agent densities appropriate for its size
2. **Maintainability:** Easy to locate files for specific environments
3. **Future-Ready:** Prepared for multi-environment comparison studies
4. **Clean Git History:** Separate worlds don't interfere with each other

### Crowd Density Rationale

**Café (Current - 12 agents):**
- Spawn region: ~127.5 m² (8.5m × 15m)
- Density: 9.4 people/100m² (moderate-busy café)
- Matches realistic ETH/UCY café scenes

**Warehouse (Future - placeholder):**
- Expected: Larger space → more agents
- Maintain ~5-10 people/100m² density

**House (Future - placeholder):**
- Expected: Small space → fewer agents
- Maintain ~5-10 people/100m² density

**Central Tunnel (Future - placeholder):**
- Expected: Linear corridor → specialized density
- Maintain ~5-10 people/100m² density

## File Mapping

When a scenario file (e.g., `cafe_oat_balanced_baseline.yaml`) runs:

1. **Scenario reads:** `hunav_loader.ros__parameters.yaml_base_name = "agents_cafe"`
2. **System looks for:** Behavior trees named `agents_cafe__agent_[1-12]_bt.xml`
3. **Behavior trees located in:** `behavior_trees/cafe/`
4. **For each agent ID (1-12):** System loads corresponding BT file and injects agent ID

## Adding New Environments

To add support for a new environment (e.g., stadium):

1. **Create scenario folder:**
   ```bash
   mkdir -p scenarios/domenic/stadium
   ```

2. **Create behavior tree folder:**
   ```bash
   mkdir -p behavior_trees/stadium
   ```

3. **Generate scenarios** (update generator if needed):
   - Modify `generate_oat_scenarios.py` to support stadium parameter
   - Scenarios auto-generate to new location

4. **Create behavior trees** (copy + adapt):
   ```bash
   cp behavior_trees/cafe/agents_cafe__agent_1_bt.xml \
      behavior_trees/stadium/agents_stadium__agent_1_bt.xml
   # Repeat for all agents with sed to update agent IDs
   ```

5. **Launch with new config:**
   ```bash
   ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
     configuration_file:=domenic/stadium/stadium_oat_balanced_baseline.yaml
   ```
