================================================================================
CAFÉ ENVIRONMENT — OAT TESTING PARAMETERS
================================================================================

World file        : cafe.world (15 m × 20 m, indoor café with tables)
Agents            : 12 pedestrians, random-crossing goals
Configuration mode: 2 (BEH_CONF_RANDOM_NORMAL) — see note below
Launch file       : cafe_no_robot.launch.py
Scenario directory: src/hunav_gazebo_wrapper/scenarios/domenic/cafe/
Duration per run  : 120 s, recorded at 10 Hz
Total runs        : 15 (3 baseline + 4 per phase × 3 phases)


--------------------------------------------------------------------------------
1. CONFIGURATION-MODE CAVEAT
--------------------------------------------------------------------------------
Café YAMLs use behavior.configuration = 2, which causes hunav_loader to
overwrite the YAML force factors with random-normal samples at every launch.
Consequently:

  • Phase 1 (social force) and Phase 2 (goal force) results reflect random
    variation rather than the intended OAT scaling.
  • Phase 3 (max_vel) is unaffected — max_vel is not overwritten by the
    configuration mode — and its results are valid.

The Central Tunnel and Delta environments use configuration = 1 (CUSTOM) to
remove this confound and serve as the substantive OAT data.


--------------------------------------------------------------------------------
2. BASELINE PARAMETERS (across all 12 agents)
--------------------------------------------------------------------------------
Social force factor   : mean 9.15, per-agent range ~5.3–21.7   (clamp [5.0, 20.0])
Goal force factor     : mean 2.73, per-agent range ~1.28–5.55  (clamp [2.0,  5.0])
Obstacle force factor : mean 15.33                              (clamp [2.0, 50.0])
Max velocity          : mean 1.06 m/s, per-agent range 0.55–1.41 (clamp [0.0, 1.8])
Other force factor    : fixed at 20.0 for all agents


--------------------------------------------------------------------------------
3. PHASE SCALING
--------------------------------------------------------------------------------
Each phase scales one parameter across every agent by a fixed factor. All
other parameters remain at baseline.

  Phase 1 — Social force   low ×0.579   high ×2.372
  Phase 2 — Goal force     low ×0.469   high ×2.033
  Phase 3 — Max velocity   low ×0.700   high ×1.330

--------------------------------------------------------------------------------
5. LAUNCH COMMANDS
--------------------------------------------------------------------------------
Run headless (gui:=false) when recording — the Gazebo client adds noticeable
load. Use the GUI only for visual inspection.

  source ~/sfm_ws_fresh/install/setup.bash

  # Baseline (runs 1–3)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_balanced_baseline.yaml gui:=false

  # Phase 1 — social force low (runs 4–5)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_social_low.yaml gui:=false

  # Phase 1 — social force high (runs 6–7)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_social_high.yaml gui:=false

  # Phase 2 — goal force low (runs 8–9)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_goal_low.yaml gui:=false

  # Phase 2 — goal force high (runs 10–11)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_goal_high.yaml gui:=false

  # Phase 3 — speed slow (runs 12–13)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_speed_slow.yaml gui:=false

  # Phase 3 — speed fast (runs 14–15)
  ros2 launch hunav_gazebo_wrapper cafe_no_robot.launch.py \
    configuration_file:=domenic/cafe/cafe_oat_speed_fast.yaml gui:=false


--------------------------------------------------------------------------------
6. RECORDING (per run)
--------------------------------------------------------------------------------
In a second terminal, after the simulation has finished loading:

  source ~/sfm_ws_fresh/install/setup.bash
  python3 src/analysis/run_recording.py <run_id>

Output is written to:
  sim_results/cafe/<phase_dir>/run_<run_id>/true_pos_.csv


--------------------------------------------------------------------------------
7. PER-PHASE ANALYSIS
--------------------------------------------------------------------------------
After all runs in a phase complete, build that phase's dashboard:

  python3 src/analysis/crowd_dynamics_evaluator.py \
    --custom-dataset run_1 sim_results/cafe/cafe_baseline/run_1/true_pos_.csv \
    --custom-dataset run_2 sim_results/cafe/cafe_baseline/run_2/true_pos_.csv \
    --custom-dataset run_3 sim_results/cafe/cafe_baseline/run_3/true_pos_.csv \
    --output-dir sim_results/cafe/cafe_baseline/analysis --dt 0.1

To regenerate every figure across all environments in one pass:
  bash regenerate_all_plots.sh
