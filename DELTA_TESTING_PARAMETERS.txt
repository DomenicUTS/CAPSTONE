================================================================================
DELTA (TRIANGLE) ENVIRONMENT — OAT TESTING PARAMETERS
================================================================================

World file        : delta.world (equilateral triangle, ~55 m sides, obstacle-free)
Agents            : 80 pedestrians, three-way crossing flow
                      27 from the top vertex
                      27 from the bottom-left vertex
                      26 from the bottom-right vertex
Groups            : 9 dyads + 6 triads + 29 individuals (15 groups total)
Configuration mode: 1 (BEH_CONF_CUSTOM) — YAML values used exactly as written
Launch file       : delta_no_robot.launch.py
Scenario directory: src/hunav_gazebo_wrapper/scenarios/domenic/delta/
Generator script  : src/hunav_gazebo_wrapper/scenarios/domenic/
                    generate_delta_yamls.py (seed = 42)
Duration per run  : 120 s, recorded at 10 Hz
Total runs        : 19 (3 baseline + 4 per phase × 4 phases)

Triangle vertices (world coordinates):
  Top          : (-6.3,  22.15)
  Bottom-left  : (-27.6, -14.30)
  Bottom-right : ( 14.7, -14.30)

Cabinets that previously sat inside the triangle were removed to eliminate the
obstacle-AABB trapping seen in the central tunnel. Delta therefore provides
the cleanest signal for pure SFM parameter effects.


--------------------------------------------------------------------------------
1. BASELINE PARAMETERS (per agent, seed = 42)
--------------------------------------------------------------------------------
Social force factor   : mean 10.85, range [7.08, 14.90]   (clamp [5.0, 20.0])
Goal force factor     : mean  3.27, range [2.50,  4.11]   (clamp [2.0,  5.0])
Obstacle force factor : mean 17.57, range [10.01, 24.56]  (clamp [2.0, 50.0])
Max velocity          : mean  1.21, range [0.99,  1.49]   (clamp [0.0,  1.8])
Goal distance         : ~25–35 m per cross-triangle traversal (cyclic)


--------------------------------------------------------------------------------
2. PHASE SCALING (matches Central Tunnel for cross-environment comparison)
--------------------------------------------------------------------------------
Each phase scales one parameter across every agent by a fixed factor. All
other parameters remain at baseline.

  Phase 1 — Social force     low ×0.55   high ×1.70
  Phase 2 — Goal force       low ×0.60   high ×1.60
  Phase 3 — Max velocity     low ×0.75   high ×1.25
  Phase 4 — Obstacle force   low ×0.50   high ×2.00

--------------------------------------------------------------------------------
4. LAUNCH COMMANDS
--------------------------------------------------------------------------------
Always run headless (gui:=false) when recording — with 80 agents the Gazebo
client is heavily GPU-intensive and will distort the recording timing. Use
the GUI only for visual inspection of the world.

  source ~/sfm_ws_fresh/install/setup.bash

  # Baseline (runs 1–3)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_baseline.yaml gui:=false

  # Phase 1 — social force low (runs 4–5)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase1_social_low.yaml gui:=false

  # Phase 1 — social force high (runs 6–7)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase1_social_high.yaml gui:=false

  # Phase 2 — goal force low (runs 8–9)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase2_goal_low.yaml gui:=false

  # Phase 2 — goal force high (runs 10–11)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase2_goal_high.yaml gui:=false

  # Phase 3 — speed low (runs 12–13)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase3_speed_low.yaml gui:=false

  # Phase 3 — speed high (runs 14–15)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase3_speed_high.yaml gui:=false

  # Phase 4 — obstacle force low (runs 16–17)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase4_obstacle_low.yaml gui:=false

  # Phase 4 — obstacle force high (runs 18–19)
  ros2 launch hunav_gazebo_wrapper delta_no_robot.launch.py \
    configuration_file:=domenic/delta/delta_phase4_obstacle_high.yaml gui:=false


--------------------------------------------------------------------------------
5. RECORDING (per run)
--------------------------------------------------------------------------------
In a second terminal, after the simulation has finished loading:

  source ~/sfm_ws_fresh/install/setup.bash
  python3 src/analysis/run_recording.py <run_id>

Output is written to:
  sim_results/delta/<phase_dir>/run_<run_id>/true_pos_.csv


--------------------------------------------------------------------------------
6. PER-PHASE ANALYSIS
--------------------------------------------------------------------------------
After all runs in a phase complete:

  python3 src/analysis/crowd_dynamics_evaluator.py \
    --custom-dataset run_1 sim_results/delta/delta_baseline/run_1/true_pos_.csv \
    --custom-dataset run_2 sim_results/delta/delta_baseline/run_2/true_pos_.csv \
    --custom-dataset run_3 sim_results/delta/delta_baseline/run_3/true_pos_.csv \
    --output-dir sim_results/delta/delta_baseline/analysis --dt 0.1

Per-agent parameter variation figure:
  python3 src/analysis/plot_parameter_variation.py \
    --scenario-dir src/hunav_gazebo_wrapper/scenarios/domenic/delta/ \
    --output sim_results/delta/parameter_variation_individual_agents.png

To regenerate every figure across all environments in one pass:
  bash regenerate_all_plots.sh


--------------------------------------------------------------------------------
7. NOTES
--------------------------------------------------------------------------------
• Three-way crossing flow creates conflicts at the triangle centroid, where
  the three goal-bound streams intersect.
• The obstacle-free interior means the Phase 4 obstacle-force results reflect
  only the perimeter walls; effects are smaller in magnitude than in the
  central tunnel.
• Delta is the largest environment in the study (80 agents). The Gazebo
  client load scales with agent count, so headless launches are required for
  reliable recording timing.
